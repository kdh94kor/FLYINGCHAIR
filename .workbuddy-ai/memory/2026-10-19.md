## 미사일 피격 시 캐릭터 회전 누락 버그 수정 (index.html)

- 원인 3가지 확인:
  1. 비행 중 피격(`pendingMissileStunMs`) 후 착지 시 `finalizeIdle()` → `applyMissileStun()`으로 뒤집힘을 적용한 직후, `triggerFly`의 착지 타이머가 `transform='none'`으로 덮어써 뒤집힘이 사라짐(간헐 발생의 주 원인).
  2. `renderStage()` 전체 재빌드(innerHTML 교체) 시 인라인 transform이 사라져 X_X 표정만 남음.
  3. 게스트 클라이언트는 `applyMissileStun`을 실행하지 않아(SYNC_STATE만 수신) 뒤집힘 연출이 아예 없었음.
- 수정: 상태 기반 포즈 SSOT 도입
  - `applyMissileStunPose()`, `clearCharacterPose()`, `syncPlayerStatusVisual()` 헬퍼 추가.
  - `renderStage()` 전체/부분 렌더 양쪽에서 `syncPlayerStatusVisual()` 호출.
  - `updateStatus()`에서 `dead-missile` 진입 시 포즈를 원자적으로 적용.
  - 착지 타이머에서 transform 리셋을 `finalizeIdle()` 앞으로 이동.
  - CSS `.character-wrapper.status-dead-missile` 폴백 규칙 추가(인라인 스타일 유실 대비).

## 모바일 채팅창 높이 고정 버그 수정 (index.html)

- 원인: `visualViewport.resize` 핸들러가 `document.activeElement !== chatInput`일 때만 `keyboard-open`을 제거 → Android에서 뒤로가기로 키보드만 닫으면 input이 계속 focus 상태라 클래스가 남음. 또한 `window.innerHeight`가 `interactive-widget=resizes-content`로 이미 줄어들어 `visualViewport.height < innerHeight*0.78` 판정이 항상 false. `updateBodyState()`가 `body.className`을 통째로 덮어써 SYNC_STATE마다 클래스가 지워지는 문제도 있었음.
- 수정: `viewportBaselineH` 기반 키보드 감지(iOS occlusion / Android layout 축소 / visualViewport 축소 3중 신호), focus grace period, blur·resize·visualViewport·orientationchange·pageshow·focusout 리스너, 복구 시 강제 reflow + scrollToBottom. `updateBodyState()`는 `state-*` 클래스만 교체하도록 변경.
- CSS: `keyboard-open` 시 bottom-panel 125px→168px(min 152px), `.chat-messages-container` min-height 62px로 한 줄 붕괴 방지.
